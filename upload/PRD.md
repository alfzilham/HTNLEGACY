# Product Requirements

- Anggota mengirim file receipt dengan data dasar valid.
- Server menyimpan file dan membuat status `PENDING`.
- Admin/Bendahara memeriksa receipt secara manual.
- `APPROVED` mencatat pemasukan dan mengubah status anggota menjadi `LUNAS`.
- `REJECTED` menyimpan alasan dan membuka kembali akses submit.
- WhatsApp memakai link manual `wa.me`.
- Fitur kas, laporan, import/export, authorization, audit log, dan siklus bulanan tetap dipertahankan.
